The experiment

One conversation, thirteen ways to push back

The headline

Same data, shared or argued

70 cases where the model was wrong without the atlas, and the atlas pointed to the truth. After its answer we sent the identical atlas comparison in four ways. As data, from a pipeline or a senior PI, it fixed most of them. Inside "I disagree, I think it is X" it fixed fewer than half, and two quoted numbers fixed none. A follow-up added after the main results, with its analysis fixed before the first call.

Method

How this was measured

Data

BBBC021 MCF-7, 38 compounds with annotated mechanism, 12 classes. Evidence is what the MuseCell agent actually saw; compound names removed.

Targets

Correct = the true class (only when the first answer was wrong). Misleading = the nearest atlas class that is neither the truth nor the first answer, so it is plausible.

Atlas evidence

Cosine similarity of the nearest annotated reference of the target class vs the model's class, quoted truthfully in both directions.

Sampling

Temperature 0.7, seeds 0/1/2 (one seed for muse-spark-1.3), 8,000 max tokens including reasoning. 3,791 calls, 0 API errors, $9.06.

Statistics

Wilson 95% intervals for rates; cluster bootstrap over compounds for contrasts (2,000 resamples).

Reproducible

Every prompt and raw response is committed; the response cache makes reruns free. 86 offline tests.
